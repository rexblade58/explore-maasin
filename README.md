# Explore Maasin

React Native mobile app for discovering local places in Maasin City, Southern Leyte.

## Quick Start

```bash
npm install
npx expo start
```

## Features

- Browse 17 local places with ratings and tags
- Search by name, description, or tags
- Category filter with modern chips
- Map view with coordinates and details
- Favorites collection with heart toggle

## Screens

| Screen | Description |
| :--- | :--- |
| Home | Browse and search with category filter |
| Map | Coordinates and place details |
| Saved | Favorites collection with heart toggle |

## Tech Stack

React Native, Expo, React Navigation, Gradle (Android), Swift (iOS)
